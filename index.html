About

Hi, I'm Mehdi.

I'm an applied scientist at Amazon Web Services (AWS). Previously I was a research scientist at Meta, working on computer vision, computational photography and generative AI.

I learn best when an idea comes with a small piece of code I can run and change. This site is built the same way: each concept is explained with its math, a minimal implementation, and a figure you can interact with.

The LLM & VLM course is the main project here — a complete path from the first token to deploying multimodal models.
