The idea in one minute

MHA gives every query head its own key/value head. MQA shares one K/V head; GQA shares K/V across groups, reducing KV-cache memory while keeping multiple query heads.

Core mathematical model

\(M_{KV}\approx 2BLTH_{kv}d_hb\)

Read every symbol as a quantity with a shape or a probability. For a working implementation, confirm the definition, units, and dimensions before changing hyperparameters.

How to reason about the equation

1. Identify the fixed input. 2. Identify learned quantities and the target. 3. Check which axis is normalized or reduced. 4. Test limiting cases. 5. Compare memory and time scaling as sequence length grows.
