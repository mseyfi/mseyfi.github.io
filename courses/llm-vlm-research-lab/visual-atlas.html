How to use this atlas

Move each slider and watch real mathematical quantities change. The idea is to develop intuition before studying the complete chapter, then return and derive the equations and implement the associated PyTorch lab. All visuals are drawn with HTML/SVG so they work on GitHub Pages without embedded image files.

The atlas is a companion to the lessons, not a replacement for complete derivations and experiments. No randomly colored generic “information units.”
