Source notes and limitations

The original book's table of contents is the backbone: Vision Language Models: Building VLMs with Hugging Face (O'Reilly, 2026). The existing GitHub pages LLMMain.md, LLMStudyPlan.md and LLM_Course_Topics.md supplied the LLM topics. Historical models such as BERT, T5 and early CNNs are treated only as useful context; the main emphasis is current transformer, multimodal and video techniques.

Editorial status: This is a working version of the full course navigation with compact standalone lesson notes, interactive conceptual diagrams, mathematical references, code snippets and exercises. It is not yet a fully exhaustive textbook replacement: full derivations, validated end-to-end training code and bespoke simulations for each topic still need expansion. The generic lab slider is explicitly illustrative.
