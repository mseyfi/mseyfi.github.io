How to study

Natural narration

The old browser voice sounded robotic because it used system text-to-speech. The Natural Voice Lab provides an experimental local neural synthesis option using Kokoro in a browser. It also offers system-voice fallback. Long pages and older browsers may synthesize slowly. No API secret is required.
