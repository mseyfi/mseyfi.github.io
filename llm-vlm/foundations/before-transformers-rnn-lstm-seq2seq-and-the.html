    Before transformers: RNN, LSTM, seq2seq and the first attention

    Transformers were invented to fix specific problems of the models before them. This session builds those models, recurrent networks, LSTMs and sequence-to-sequence translation, and shows exactly where they break: vanishing gradients, a one-vector bottleneck, and steps that cannot run in parallel. Then it shows the idea that fixed the bottleneck: attention.

    Time: 3 hours (reading 2 hours, exercises 1 hour)Level: Beginner to interview levelBefore this: Sessions 2, 4 and 6

    What you will learn

    • How a recurrent neural network (RNN) carries a memory through a sequence
    • Why gradients vanish or explode through time, with the math
    • How the LSTM’s gates and cell state keep gradients alive
    • Sequence-to-sequence models and the one-vector bottleneck
    • Bahdanau attention: scores, softmax weights and a context vector, the direct ancestor of QKᵀ
    • Why self-attention replaced recurrence: parallel training and short paths, and where recurrent ideas still live (SSMs, streaming video)

    Why this matters

    Before 2017, the best language and translation models were recurrent networks. They read text one token at a time and carried a memory forward. They worked, but they had three problems, and the transformer was designed to remove all three.

    • Forgetting: gradients shrink as they travel back through many steps, so long-range patterns are hard to learn.
    • A bottleneck: a translation model had to squeeze a whole sentence into one fixed vector.
    • No parallelism: step \(t\) needs step \(t-1\), so training cannot use the GPU’s parallel power across the sequence.

    Attention was invented in 2014 to fix the bottleneck. In 2017 the transformer kept attention and threw away the recurrence. Understanding this history makes every transformer design choice obvious. And recurrent ideas are back: state space models such as Mamba (session 101) and streaming video models keep a running state much like an RNN.

    Interview tip“Why did transformers replace RNNs?” Give three reasons with their complexity: \(O(1)\) sequential steps instead of \(O(T)\) (parallel training), \(O(1)\) path length between any two tokens instead of \(O(T)\) (easier long-range learning), and no fixed-size bottleneck.

    Recurrent neural networks

    An RNN reads a sequence \(\mathbf{x}_1, \dots, \mathbf{x}_T\) and keeps a hidden state \(\mathbf{h}_t\): a vector that summarizes everything read so far. At each step it mixes the old state with the new input:

    \[ \mathbf{h}_t = \tanh\!\left( W_{hh}\, \mathbf{h}_{t-1} + W_{xh}\, \mathbf{x}_t + \mathbf{b} \right), \qquad \mathbf{y}_t = W_{hy}\, \mathbf{h}_t \tag{7.1} \]
    Read the symbols
    \(\mathbf{h}_t\)
    the memory after reading token \(t\) (size \(d_h\))
    \(W_{hh}\)
    how the old memory feeds into the new one
    \(W_{xh}\)
    how the new input enters the memory
    \(\mathbf{y}_t\)
    the output at step \(t\), for example the logits for the next token

    The same weights are used at every step. That is how an RNN handles sequences of any length with a fixed number of parameters. If you “unroll” it in time, it becomes a very deep network (one layer per token) whose layers all share weights.

    AnalogyAn RNN is a person reading a book with no notes, only a running summary in their head. After each sentence they update the summary. Early details fade as the summary is rewritten again and again.

    As a language model, the RNN predicts \(x_{t+1}\) from \(\mathbf{h}_t\) with softmax and cross-entropy, exactly as before. Unlike an n-gram model, it has no fixed window: in principle \(\mathbf{h}_t\) depends on every earlier token. In practice, the memory fades. The next section shows why.

    Training through time: vanishing and exploding gradients

    We train an RNN with ordinary backpropagation on the unrolled graph. This is called backpropagation through time (BPTT). The gradient of a loss at step \(T\) with respect to an early state \(\mathbf{h}_k\) is a product of one Jacobian per step:

    \[ \frac{\partial \mathbf{h}_T}{\partial \mathbf{h}_k} = \prod_{t=k+1}^{T} \frac{\partial \mathbf{h}_t}{\partial \mathbf{h}_{t-1}} = \prod_{t=k+1}^{T} \operatorname{diag}\!\left(1 - \mathbf{h}_t^2\right) W_{hh} \tag{7.2} \]

    The factor \(1 - \mathbf{h}_t^2\) is the derivative of tanh; it is at most 1 and close to 0 when tanh is saturated. Now picture a single number instead of a matrix: the product is like \(\rho^{T-k}\), where \(\rho\) is the typical size of one factor.

    Worked example

    Over 50 steps: \(0.9^{50} = 0.005\), so the signal from 50 tokens ago is 200 times weaker; \(1.1^{50} = 117\), so it is 117 times stronger. Over 100 steps the effect is even more extreme. A product of many numbers almost never stays near 1.

    • Vanishing gradients (\(\rho \lt 1\)): the model cannot learn that a token far back matters. This is the main reason plain RNNs forget.
    • Exploding gradients (\(\rho \gt 1\)): updates become huge and training diverges. Gradient clipping (Session 4, formula 4.13) fixes this one.

    LSTM: a memory with gates

    The Long Short-Term Memory network (Hochreiter and Schmidhuber, 1997) adds a second memory, the cell state \(\mathbf{c}_t\), which is changed by adding things, not by squashing it through a matrix and tanh at every step. Three gates, each a number between 0 and 1 per dimension, control it:

    \[ \begin{aligned} \mathbf{f}_t &= \sigma\!\left(W_f [\mathbf{h}_{t-1}; \mathbf{x}_t] + \mathbf{b}_f\right) &&\text{forget gate} \\ \mathbf{i}_t &= \sigma\!\left(W_i [\mathbf{h}_{t-1}; \mathbf{x}_t] + \mathbf{b}_i\right) &&\text{input gate} \\ \mathbf{o}_t &= \sigma\!\left(W_o [\mathbf{h}_{t-1}; \mathbf{x}_t] + \mathbf{b}_o\right) &&\text{output gate} \\ \tilde{\mathbf{c}}_t &= \tanh\!\left(W_c [\mathbf{h}_{t-1}; \mathbf{x}_t] + \mathbf{b}_c\right) &&\text{candidate} \\ \mathbf{c}_t &= \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t, \qquad \mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{c}_t) \end{aligned} \tag{7.3} \]

    Here \(\odot\) is element-wise multiplication and \([\cdot\,;\cdot]\) is concatenation. Read the cell update in words: keep a fraction \(\mathbf{f}_t\) of the old memory, and add a fraction \(\mathbf{i}_t\) of new information. The output gate decides how much of the memory to show.

    AnalogyThe cell state is a conveyor belt running along the sequence. Gates are workers who can take items off (forget), put items on (input) and show items to the next station (output). Items that nobody touches ride along unchanged.

    Why does this help gradients? Along the cell state, the local derivative is just the forget gate:

    \[ \frac{\partial \mathbf{c}_t}{\partial \mathbf{c}_{t-1}} = \operatorname{diag}(\mathbf{f}_t) \quad \Rightarrow \quad \frac{\partial \mathbf{c}_T}{\partial \mathbf{c}_k} \approx \prod_{t=k+1}^{T} \operatorname{diag}(\mathbf{f}_t) \tag{7.4} \]

    No weight matrix and no tanh in this path. If the network learns \(f \approx 1\) for an important dimension, the signal passes almost untouched; it can also learn \(f \approx 0\) to forget on purpose. This additive path is the same idea as the residual stream in a transformer (Session 1, formula 1.5). A common trick is to initialize the forget-gate bias to 1 or 2, so memory is kept by default. [Likely]

    The GRU (Cho et al., 2014) is a lighter variant with two gates and no separate cell state; it often works about as well as an LSTM. [Likely]

    Sequence to sequence, and the bottleneck

    For translation, the input and output have different lengths. The sequence-to-sequence model (Sutskever et al., 2014) uses two RNNs. The encoder reads the source sentence and ends in a final state \(\mathbf{c} = \mathbf{h}_{T_x}\). The decoder starts from \(\mathbf{c}\) and generates the target one token at a time:

    \[ p(y_1, \dots, y_{T_y} \mid \mathbf{x}) = \prod_{t=1}^{T_y} p\!\left(y_t \mid y_{\lt t},\ \mathbf{c}\right) \tag{7.5} \]

    The weakness is plain in the formula: everything the decoder knows about the source is in one fixed-size vector \(\mathbf{c}\), whether the sentence has 5 words or 50. Translation quality of such models dropped for long sentences. [Likely]

    AnalogySeq2seq without attention is translating a long speech after hearing it once, using only one sticky note of memory. Attention lets the translator look back at the full transcript while speaking.

    Attention: look back at every input

    Bahdanau, Cho and Bengio (2014) kept all encoder states \(\mathbf{h}_1, \dots, \mathbf{h}_{T_x}\). At each decoder step \(t\), the decoder state \(\mathbf{s}_{t-1}\) scores every encoder state, softmax turns the scores into weights, and the weighted sum becomes a fresh context vector for this step:

    \[ e_{tj} = \mathbf{v}^\top \tanh\!\left( W \mathbf{s}_{t-1} + U \mathbf{h}_j \right), \qquad \alpha_{tj} = \frac{e^{e_{tj}}}{\sum_{k} e^{e_{tk}}}, \qquad \mathbf{c}_t = \sum_{j=1}^{T_x} \alpha_{tj}\, \mathbf{h}_j \tag{7.6} \]

    This is the first attention. Compare it with Session 2, formula (2.20): a score per pair, a softmax over the inputs, a weighted sum. The decoder state plays the role of the query, the encoder states are both keys and values. Luong et al. (2015) simplified the score to a dot product, \(e_{tj} = \mathbf{s}_t^\top \mathbf{h}_j\) (or \(\mathbf{s}_t^\top W \mathbf{h}_j\)), which is one step from \(\mathbf{q}^\top \mathbf{k}\). The weights \(\alpha_{tj}\) form an alignment between target and source words, learned with no alignment labels at all.

    From attention to the transformer

    Once the decoder can look at all encoder states, why keep the RNNs at all? The transformer (Vaswani et al., 2017) lets every position attend to every other position in the same sequence (self-attention), with no recurrence. The comparison from the paper explains the switch:

    Layer typeCost per layerSequential stepsLongest path between two tokens
    Self-attention\(O(n^2 d)\)\(O(1)\)\(O(1)\)
    Recurrent\(O(n d^2)\)\(O(n)\)\(O(n)\)
    Convolution (kernel \(k\))\(O(k n d^2)\)\(O(1)\)\(O(\log_k n)\)

    \(O(1)\) sequential steps means the whole sequence trains in parallel on a GPU. A path length of \(O(1)\) means a gradient between any two tokens passes through a constant number of layers, so nothing vanishes over distance. The price is the \(O(n^2)\) cost in sequence length, which is what all of Track 5’s efficient attention work tries to reduce.

    Where recurrence still wins

    At inference, an RNN keeps a fixed-size state, so each new token costs the same and memory does not grow. A transformer keeps a KV cache that grows with every token (session 80). For very long or endless streams (live audio, live video), that difference matters. State space models and linear-attention models try to get transformer-quality training with RNN-style constant-memory inference.

    Pseudo-code

    Algorithm 1: one LSTM step (formula 7.3)
    1. input: \(\mathbf{x}_t\), \(\mathbf{h}_{t-1}\), \(\mathbf{c}_{t-1}\), weights \(W \in \R^{4d_h \times (d_h + d_x)}\), bias \(\mathbf{b}\)
    2. \(\mathbf{a} \leftarrow W[\mathbf{h}_{t-1}; \mathbf{x}_t] + \mathbf{b}\) // one matmul for all four parts
    3. split \(\mathbf{a}\) into \(\mathbf{a}_f, \mathbf{a}_i, \mathbf{a}_o, \mathbf{a}_c\) (each size \(d_h\))
    4. \(\mathbf{f}, \mathbf{i}, \mathbf{o} \leftarrow \sigma(\mathbf{a}_f), \sigma(\mathbf{a}_i), \sigma(\mathbf{a}_o)\); \(\;\tilde{\mathbf{c}} \leftarrow \tanh(\mathbf{a}_c)\)
    5. \(\mathbf{c}_t \leftarrow \mathbf{f} \odot \mathbf{c}_{t-1} + \mathbf{i} \odot \tilde{\mathbf{c}}\) // additive memory
    6. return \(\mathbf{h}_t = \mathbf{o} \odot \tanh(\mathbf{c}_t)\), \(\mathbf{c}_t\)
    Algorithm 2: one decoder step with attention (formula 7.6)
    1. input: decoder state \(\mathbf{s}\), encoder states \(H \in \R^{T_x \times d}\), previous output token \(y\)
    2. for \(j = 1\) to \(T_x\) do \(e_j \leftarrow \mathbf{v}^\top \tanh(W\mathbf{s} + U\mathbf{h}_j)\) // or \(\mathbf{s}^\top \mathbf{h}_j\) (Luong)
    3. \(\alpha \leftarrow \softmax(\mathbf{e})\); \(\;\mathbf{c} \leftarrow \alpha^\top H\) // context vector
    4. \(\mathbf{s} \leftarrow \text{RNNcell}([\text{embed}(y); \mathbf{c}],\ \mathbf{s})\)
    5. return logits \(= W_{\text{out}}[\mathbf{s}; \mathbf{c}]\), new state \(\mathbf{s}\), weights \(\alpha\)
    import torch, torch.nn as nn
torch.manual_seed(0)
B, T, d_in, d_h = 2, 7, 16, 32
lstm = nn.LSTM(d_in, d_h, batch_first=True)          # formula (7.3), all steps in one call
x = torch.randn(B, T, d_in)
H, (h_T, c_T) = lstm(x)                              # H: (B, T, d_h) every state; h_T, c_T: (1, B, d_h)
with torch.no_grad():                                 # forget-gate bias = 1 (PyTorch order: i, f, g, o)
    lstm.bias_ih_l0[d_h:2 * d_h].fill_(1.0)

class AdditiveAttention(nn.Module):                   # Bahdanau, formula (7.6)
    def __init__(self, d_s, d_h, d_a=64):
        super().__init__()
        self.W, self.U, self.v = nn.Linear(d_s, d_a, bias=False), nn.Linear(d_h, d_a, bias=False), nn.Linear(d_a, 1, bias=False)
    def forward(self, s, H):                          # s: (B, d_s), H: (B, T, d_h)
        e = self.v(torch.tanh(self.W(s)[:, None, :] + self.U(H))).squeeze(-1)   # (B, T) scores
        a = torch.softmax(e, dim=-1)                  # weights over source positions
        return (a[:, :, None] * H).sum(1), a           # context (B, d_h), weights (B, T)

ctx, a = AdditiveAttention(d_h, d_h)(h_T[0], H)
print(ctx.shape, a.sum(-1))                           # torch.Size([2, 32]) and ones

    Common mistakes

    • Using the last output of a padded batch. With padding, the “last” step is padding for short sequences. Use pack_padded_sequence or gather the true last index.
    • No gradient clipping for RNNs. Exploding gradients are common; clip the global norm.
    • Forgetting gate order. PyTorch stores LSTM gates as input, forget, cell, output. Initializing the “forget bias” at the wrong slice changes a different gate.
    • Masking attention over padding. Set scores of padded source positions to \(-\infty\) before softmax, or the model attends to padding.
    • Calling attention weights an explanation. Alignments are suggestive, not proof of what the model used.

    Interview questions

    Why do gradients vanish or explode in RNNs?core
    BPTT multiplies one Jacobian \(\operatorname{diag}(1-\mathbf{h}_t^2)W_{hh}\) per step (formula 7.2). The product of many such factors shrinks to zero if their typical size is below 1 and blows up if it is above 1; tanh saturation pushes toward vanishing. Clipping fixes explosion; gating (LSTM/GRU), careful initialization and shorter paths fix vanishing.
    How does the LSTM help with vanishing gradients?core
    The cell state is updated additively, \(\mathbf{c}_t = \mathbf{f}_t\odot\mathbf{c}_{t-1} + \mathbf{i}_t\odot\tilde{\mathbf{c}}_t\), so the gradient along it is multiplied only by the forget gate (formula 7.4), with no weight matrix and no tanh. With \(f\approx1\) the signal survives many steps. It is the same principle as residual connections.
    What is the bottleneck in seq2seq, and how does attention remove it?basic
    Without attention the decoder sees the source only through one fixed vector, the final encoder state, regardless of sentence length. Attention keeps every encoder state and computes a new weighted context vector at each decoder step, so the decoder can focus on the relevant source words.
    Write Bahdanau attention and relate it to transformer attention.core
    \(e_{tj} = \mathbf{v}^\top\tanh(W\mathbf{s}_{t-1} + U\mathbf{h}_j)\), \(\alpha = \softmax(e)\), \(\mathbf{c}_t = \sum_j \alpha_{tj}\mathbf{h}_j\). The decoder state is the query; encoder states are keys and values. Luong’s dot-product score and then the transformer’s scaled dot product \(\mathbf{q}^\top\mathbf{k}/\sqrt{d}\) with separate projections for Q, K and V are direct descendants; additive attention costs more because of the extra tanh layer.
    Compare self-attention and recurrence in complexity.core
    Self-attention: \(O(n^2 d)\) per layer, \(O(1)\) sequential operations, \(O(1)\) maximum path length. Recurrent: \(O(nd^2)\), \(O(n)\) sequential, \(O(n)\) path. Attention is faster to train on GPUs and learns long-range links more easily, but costs quadratic time and a growing KV cache in sequence length.
    When would you still use a recurrent model today?advanced
    For streaming with strict memory and latency limits (constant state per step), very long or unbounded streams, or tiny on-device models. For example, a GRU head over frame embeddings from a frozen encoder for live event detection, or state space models for long sequences. For most offline language tasks, transformers or hybrids win.
    What does an LSTM’s forget-gate bias initialization of 1 do?basic
    \(\sigma(1)\approx0.73\) at the start, so the cell keeps most of its memory by default instead of forgetting half of it each step. This makes gradients flow better early in training. [Likely]
    Why is BPTT memory-hungry, and what is truncated BPTT?advanced
    Backprop needs the hidden state at every step, so memory grows with sequence length, like activations in any deep network. Truncated BPTT backpropagates through only the last \(K\) steps while carrying the state forward, trading long-range credit assignment for bounded memory.

    Key takeaways

    • An RNN (7.1) carries a fixed-size memory with shared weights; BPTT multiplies Jacobians (7.2), so gradients vanish or explode over long distances.
    • The LSTM (7.3) keeps memory on an additive path whose gradient is just the forget gate (7.4): the same idea as residual connections.
    • Seq2seq (7.5) squeezes the source into one vector; attention (7.6) replaces it with a fresh weighted context per output step, learned alignments included.
    • Self-attention gives \(O(1)\) sequential steps and \(O(1)\) paths at \(O(n^2)\) cost; recurrence keeps \(O(1)\) inference memory, which is why SSMs and streaming models bring it back.
