Capstone

Read a modern model end to end, then design, build and evaluate a sports key-moment search system.

234

Dissect a modern open model

  • Pick one, for example Gemma 4, Qwen3, DeepSeek-V3 or Qwen2.5-VL
  • From the config: layers, heads, KV heads, experts, vision tower, context length
  • Compute parameters, FLOPs per token, KV cache per token, memory to serve
  • Read its technical report and explain every design choice with what you learned

Capstone design: sports key-moment search

  • Requirements: queries, latency, accuracy, cost, hardware (L4 + TensorRT)
  • Design: segmenting, embedding, indexing, VLM re-ranking, timestamps
  • Latency and cost math before building
  • Risks, failure modes, and what to measure
