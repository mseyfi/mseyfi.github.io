Post-training 2: alignment and reinforcement learning

Policies, rewards and preferences: PPO, RLHF, DPO and its family, GRPO, reasoning models.

63

Reinforcement learning words, for LLMs

  • Agent, environment, state, action, reward, return, episode
  • Text generation as RL: state = prompt + text so far, action = next token, policy = the LLM
  • Sparse rewards that come only at the end of an answer
  • Why RL and not only SFT: learn from a score, not from a copy
Ready
64

Policy gradient and REINFORCE

  • The log-derivative trick: ∇E[R] = E[R ∇log π]
  • REINFORCE for a whole generated answer
  • High variance, and baselines that add no bias
  • Advantage = how much better than expected

Value functions, advantage and GAE

  • The TD error; the bias–variance trade-off
  • Generalized Advantage Estimation with γ and λ
  • Actor–critic: a policy plus a learned critic

PPO

DPO: alignment without a separate reward model

  • Start from the KL-regularized RL objective
  • Its closed-form best policy turns the reward into a log-ratio
  • Put that into Bradley–Terry and you get the DPO loss
  • β, the reference model, and what DPO can and cannot do (offline data)
Ready
69

The DPO family: IPO, KTO, ORPO, SimPO

  • IPO: fixes overfitting when preferences are almost certain
  • KTO: works with single thumbs-up or thumbs-down labels
  • ORPO: SFT and preference in one loss, no reference model
  • SimPO: length-normalized reward, no reference model
Ready
70

GRPO and RL with verifiable rewards (RLVR)

  • Sample a group of answers for each prompt; normalize rewards inside the group
  • No critic model: a big memory saving
  • Verifiable rewards: math answers, unit tests, format checks
  • From DeepSeekMath to DeepSeek-R1; known issues and fixes (length bias, std normalization)
